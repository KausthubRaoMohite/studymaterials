# DSA Master Roadmap

This roadmap is designed to build deep understanding first, followed by
problem-solving ability and interview readiness.

------------------------------------------------------------------------

# Phase 0 --- Mathematical Foundation

## Complexity Analysis

Learn: - Time Complexity - Space Complexity - Best, Average, Worst
Case - Big O - Big Ω - Big Θ - Amortized Complexity - Constant Factors

Understand: - O(1) - O(log n) - O(n) - O(n log n) - O(n²) - O(2ⁿ) -
O(n!)

## Recursion

Learn: - Stack Frames - Base Case - Recursive Case - Backtracking - Tail
Recursion - Divide and Conquer

Practice: - Factorial - Fibonacci - Sum of Array - Reverse String -
Recursive Binary Search

------------------------------------------------------------------------

# Phase 1 --- Arrays

Understand: - Memory Layout - Indexing - Dynamic Arrays - Contiguous
Memory

Operations: - Insert - Delete - Rotate - Reverse - Prefix Sums -
Difference Arrays

Patterns: - Sliding Window - Two Pointers - Fast & Slow Pointer - Prefix
Sum

------------------------------------------------------------------------

# Phase 2 --- Strings

Learn: - ASCII - Unicode - UTF-8 - Mutable vs Immutable Strings

Algorithms: - Naive Search - KMP - Rabin-Karp - Z Algorithm - Trie
Introduction

Patterns: - Frequency Counting - Sliding Window - Hashing

------------------------------------------------------------------------

# Phase 3 --- Linked Lists

Types: - Singly - Doubly - Circular

Operations: - Insert - Delete - Reverse - Merge - Split

Algorithms: - Floyd Cycle Detection - Merge Lists - Intersection - LRU
Foundation

------------------------------------------------------------------------

# Phase 4 --- Stacks

Concepts: - LIFO - Expression Evaluation - Undo Operations - DFS

Problems: - Monotonic Stack - Largest Rectangle - Next Greater Element -
Min Stack

------------------------------------------------------------------------

# Phase 5 --- Queues

Concepts: - Queue - Circular Queue - Deque - Priority Queue (Intro)

Applications: - BFS - Scheduling - Producer--Consumer

Problems: - Sliding Window Maximum - Rotten Oranges - Task Scheduler

------------------------------------------------------------------------

# Phase 6 --- Hashing

Learn: - Hash Functions - Collision Handling - Load Factor - Chaining -
Open Addressing

Applications: - Frequency Counting - Deduplication - Caching

Problems: - Two Sum - Valid Anagram - Longest Consecutive Sequence - LRU
Cache

------------------------------------------------------------------------

# Phase 7 --- Binary Search

Topics: - Binary Search on Index - Binary Search on Answer - Predicate
Search - Infinite Arrays - Rotated Arrays - Peak Element

Problems: - Aggressive Cows - Book Allocation - Capacity to Ship
Packages - Median of Two Sorted Arrays

------------------------------------------------------------------------

# Phase 8 --- Trees

Learn: - Tree Terminology - Height - Depth - Leaves - Internal Nodes

Traversals: - Preorder - Inorder - Postorder - Level Order

Tree Types: - Balanced - Perfect - Complete - Full

------------------------------------------------------------------------

# Phase 9 --- Binary Search Trees

Topics: - Insert - Delete - Search - Floor & Ceil - Successor &
Predecessor - Validation - Lowest Common Ancestor

------------------------------------------------------------------------

# Phase 10 --- Heaps

Learn: - Min Heap - Max Heap - Heapify - Priority Queue

Algorithms: - Heap Sort

Problems: - Top-K Elements - Merge K Lists - Task Scheduler

------------------------------------------------------------------------

# Phase 11 --- Tries

Applications: - Prefix Search - Autocomplete - Dictionary - Maximum
XOR - Word Search

------------------------------------------------------------------------

# Phase 12 --- Graph Theory

Representations: - Adjacency List - Adjacency Matrix - Edge List

Traversal: - DFS - BFS - Connected Components - Cycle Detection -
Topological Sort

Shortest Path: - Dijkstra - Bellman-Ford - Floyd-Warshall - 0-1 BFS

Minimum Spanning Tree: - Prim - Kruskal - Union-Find

Advanced: - Kosaraju - Tarjan - Bridges - Articulation Points - Euler
Path - Hamiltonian Path

------------------------------------------------------------------------

# Phase 13 --- Greedy Algorithms

# Phase 14 --- Backtracking

# Final Phase --- Algorithm Design

Develop the ability to: 1. Analyze problem constraints. 2. Estimate
acceptable time complexity. 3. Select the right data structure. 4.
Combine multiple algorithmic techniques. 5. Prove correctness. 6.
Evaluate time--space trade-offs.
